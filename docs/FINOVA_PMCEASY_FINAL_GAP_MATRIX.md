# Finova ↔ PMCEASY — Phase 9 final gap matrix

14 November 2026, Asia/Karachi. This updates all **23 Phase 6A gaps** against current source and reproducible synthetic behavior. It does not assert exact target parity or clinical validation. The [functional audit](FINOVA_PHASE9_FUNCTIONAL_AUDIT.md) owns verification results and their snapshot limits; the [checklist](FINOVA_PROJECT_COMPLETION_CHECKLIST.md) owns remaining submission/release work.

## Reading the matrix

**REAL** means working independent engineering functionality. **SYNTHETIC** means an executable example with supplied invented semantics/content; it does not mean a clinical algorithm. **MISSING/BLOCKED** distinguishes unbuilt systems from unavailable reviewed data/policy. **UNKNOWN TARGET** means target behavior was not established. A row may combine these states.

Prior status is the historical [Phase 6A matrix](docs/PMCEASY_FEATURE_GAP_MATRIX.md), not a current claim. Target evidence uses its P/V/L identifiers from the [research source register](docs/PMCEASY_FUNCTIONAL_RESEARCH_REPORT.md) and [observation register](evidence/pmceasy-phase6a/screenshot-observation-register.json). Public recordings establish visible categories in those recordings; advertising is weaker evidence. There was no current paid-runtime comparison, authentic clipboard capture or private algorithm inspection. Historical research artifact hashes do not make current code behavior authoritative.

Priorities below are for a credible final prototype: **P0** required truthful boundary/demo/release blocker; **P1** useful presentation/evidence improvement; **P2** optional/outside submission scope. Clinical/vendor blockers are P0 *before a claim of clinical/vendor capability*, but do not require unauthorized implementation for a synthetic project submission.

## What changed since Phase 6A

The largest engineering closures are GAP02's connected journeys, GAP03's purpose navigation, GAP05's conservative dimension presentation, GAP09/20's explicit local exports/selection, GAP15's attachment interface and GAP17/18's textual Nano/side-specific surfaces. GAP15–18 retain supplied fictional content rather than clinical computation. GAP01/23 remain working delivery/intake capabilities.

GAP04/07/08/10/11/14 and the clinical portions of GAP05/06/15/16/17/18 remain substantive missing data/policy/implementation/validation systems. GAP12/13 are absent optional product surfaces. GAP19–22 retain unknown target facts even where Finova offers independent functionality. No new UI card, fixed example, environment flag, model response or passing software test closes those external evidence gates.
